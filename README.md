# Tiki Tiki Phonk Clicker

A phonk-themed idle clicker game with:

- click-to-earn vibes
- phonk style unlocks and multipliers
- upgrades for click power
- passive income upgrades
- rebirth system with permanent power bonuses
- local save progress
- phonk-style synth beat audio

## Run it

Open `index.html` in a browser.

## Controls

- Click the big phonk button to gain vibes.
- Unlock styles to increase click multiplier.
- Buy upgrades for stronger clicks.
- Buy passive income to generate vibes automatically.
- Rebirth when you have enough progress to gain permanent power.
- Toggle sound on/off.
